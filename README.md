# WeebCentral Exporter V1.6
A Universal lightweight tool to load and export WeebCentral subscriptions instantly!

## What It Does

- Exports any WeebCentral subscription list
- Algorithm sorts by last subscribed
- Removes formatting artifacts and cleanly exports
- Extracts all titles with one click
- Works on all profiles
- No annoying installation, setup, or dependencies required
- Bypasses restrictions and API
- Works on every device

## Features

- **Lightning fast** — extracts in seconds
- **Universal Export** — extracts anyone's subscriptions
- **No setup** — runs directly in your browser
- **Works on both pages** — subscriptions list and profiles
- **Auto-cleanup** — strips junk from titles automatically
- **Console Support** — if you want to use console
- **Auto Detection** — detects if you're on the wrong page


## Supported Pages

- `https://weebcentral.com/users/me/subscriptions`
- `https://weebcentral.com/users/{userId}/profiles/subscriptions`

## What You Can Do With It

- Share your manga list with friends
- Keep a clean backup of your subscriptions
- Import into apps and websites
- Organize your reading list 

## Technical Details

The Exporter:
1. Uses API to find all subscriptions
2. Exports subscription titles
3. Removes formatting artifacts
4. Copies results to clipboard
5. Shows confirmation alert

## Notes

- Requires JavaScript enabled in your browser
- Works best on PC but does work on all devices
- Clipboard access requires browser permission
